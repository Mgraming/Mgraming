# 📘 باسبور العربية (Car Passport) — MVP

قصة حياة العربية من يوم الشراء لحد البيع: سجل صيانة، تذكيرات، وتقرير تاريخ العربية اللي بيتشارك بـ QR عشان العربية تتباع أسرع وبسعر أحسن.

## اللي في الـ MVP

- **باسبور لكل عربية**: بيانات العربية، العداد وقت الشراء، مواعيد انتهاء الرخصة والتأمين، ويدعم أكتر من عربية.
- **سجل صيانة**: النوع، التاريخ، العداد، التكلفة، الورشة، قطع الغيار ونوعها (أصلي / OEM / بديل / مستعمل)، وصورة الفاتورة (بتتصغّر تلقائياً).
- **تذكيرات ذكية**: محسوبة من آخر مرة بالكيلومترات وبالوقت (زيت، فلاتر، فرامل، كاوتش، بطارية، …) + الرخصة والتأمين.
- **كشف تعارض العداد**: أي قراءة أقل من قراءة قبلها بتتعلّم في السجل وفي التقرير.
- **درجة السجل (٠–١٠٠)**: توثيق بالفواتير (٤٠) + الالتزام بالمواعيد (٣٠) + تسلسل العداد (٣٠)، مع نصايح إزاي ترفعها.
- **التكاليف**: صرفت السنة دي، الإجمالي، وتكلفة الكيلو.
- **تقرير تاريخ العربية**: لينك + QR من غير سيرفر (البيانات مضغوطة جوه اللينك نفسه). اللوحة والشاسيه متخبيين جزئياً، ومفيش اسم المالك ولا صور الفواتير، وفي اختيار لإخفاء التكاليف.
- **نقل الملكية**: تنزيل ملف الباسبور واستيراده عند المالك الجديد.
- **دليل لمبات التابلوه** بمستوى الخطورة.
- **PWA**: يتسطّب على الموبايل ويشتغل من غير نت.

## التشغيل

```bash
npm start          # http://localhost:8080
npm test           # اختبارات منطق التذكيرات والعداد والدرجة والتقرير
```

مش محتاج build. لازم يتفتح من سيرفر (مش `file://`) عشان ES modules. ينفع يتنشر زي ما هو على GitHub Pages أو Netlify.

## الهيكل

| الملف | الدور |
|---|---|
| `js/data.js` | أنواع الصيانة وفتراتها، مصادر السجل، لمبات التابلوه |
| `js/logic.js` | منطق نقي قابل للاختبار: تذكيرات، تعارض العداد، الدرجة، التكاليف، ترميز التقرير |
| `js/store.js` | تخزين محلي (localStorage) + تصدير واستيراد |
| `js/app.js` | الشاشات والتنقّل |
| `report.html`, `js/report.js` | صفحة تقرير تاريخ العربية للمشتري |
| `vendor/qrcode.js` | مولّد QR (MIT, Kazuhiko Arase) |

## حدود الـ MVP (لازم تبقى واضحة)

- البيانات **على الموبايل بس**. لو الموبايل ضاع من غير نسخة احتياطية، البيانات بتضيع.
- السجلات **مسجّلة من المالك** ومش موثّقة من جهة تانية. صورة الفاتورة بتزوّد الدرجة بس مش بتثبت صحتها. التقرير بيوضّح ده للمشتري.
- فترات الصيانة **عامة**، وكتالوج العربية هو المرجع.

## الخطوات الجاية

1. **Backend وحسابات**: مزامنة ونسخ احتياطي سحابي، ولينك تقرير قصير ثابت.
2. **تطبيق الورشة**: الورشة تسجّل الشغل بسكان QR العربية، والسجل يتختم رقمياً (المصدر `workshop` محجوز في `data.js`).
3. **قراءة الفاتورة تلقائياً (OCR)** و**«السعر العادل»** من بيانات الفواتير.
4. **ميكانيكي بالذكاء الاصطناعي**: صورة اللمبة أو صوت العطل ← تشخيص استرشادي.
5. **ماركت قطع الغيار والورش**، وتقارير مدفوعة للمشترين.
